# Customer API (Spring Boot)

Crear un API con Spring Boot para Customers, siguiendo el mismo patron visto en clase.

Debe contar con los siguientes endpoints:

- Obtener todos
  - GET /customers
- Obtener 1 por id
  - GET /customers/{id}
- Crear customer
  - POST /customers
- Eliminar customer por id
  - DELETE /customers/{id}
